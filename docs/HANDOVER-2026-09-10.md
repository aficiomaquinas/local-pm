## 4. Quirks técnicos descubiertos (crítico para no re-tropezar)

### 4.1 Payload 3.88 — `disableLocalStrategy` truthy = login 403 SIEMPRE
`auth/operations/login.js:31` (payload dist): `loginOperation` lanza `Forbidden` si
`collectionConfig.auth.disableLocalStrategy` es **truthy** — y la forma objeto
(`{ enableFields, optionalPassword }`) es truthy. SPC-006 M1 la usó creyendo que el
sanitizer la trataba como `false` → login/first-register 403 para todos → el operador no
podía crear proyectos. **Fix**: omitir la key; `strategies` no la requiere
(`IncomingAuthType.strategies?` es opcional). Fix en `40155b3`; M7 flip = `true` gated.

### 4.2 Builder Docker vs tests — hermeticidad forzada
Los handlers OIDC llaman `getPayload()` → mongoose. Con `DATABASE_URI` válida-pero-
inalcanzable (la inyectaba compose como build-arg), mongoose reintentaba 30s >
testTimeout 5s → 2 tests logout expiraban SOLO en `docker compose build`. Fix en dos
capas: o2 fija `DATABASE_URI=mongodb://127.0.0.1:1/...?serverSelectionTimeoutMS=1` en
`beforeEach`, y el Dockerfile corre `RUN DATABASE_URI="" pnpm -r --no-bail test`.
Detalle completo: `docs/investigations/2026-09-10_docker-builder-tests-mongoose-timeout.md`.
Adicionalmente, master lleva `serverSelectionTimeoutMS: 3000` en el adapter + healthcheck
gate de mongo (merge `0f44a73`, de la rama `fix/builder-mongo-serverselection`).

### 4.3 dnd-kit — keyboard drag (a11y)
`attributes` (role/tabindex) iban al root de la card y `listeners` al div interno
no-focusable; `setActivatorNodeRef` nunca usado → keyboard drag jamás activaba. Fix
mergeado; upstream PR #5 abierto. Quirks para tests futuros: `fireEvent.keyDown` NO deriva
`code` desde `key` (dnd-kit lee `nativeEvent.code`); el listener en-drag vive en el owner
**document** (attach via `setTimeout(0)`); `KeyboardCode.Esc === 'Escape'` en core 6.x.

### 4.4 dex v2.45.1 — sin `client_credentials`
PR #4583 mergeado sin release en ese tag → la pata MCP (machine grant) devuelve 400.
La pata web (PKCE) sí funciona E2E. Documentado en `config/dex/config.yml` y en el header
del compose. **Esto motiva la investigación de alternativas en vuelo** (§6).
